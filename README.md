# 🦸 Superman Voxel Simulator

شبیه‌ساز سوپرمن در دنیای ماینکرافت — یک بازی مرورگری سه‌بعدی با Three.js

## اجرا

فایل `index.html` را در مرورگر باز کنید (نیاز به internet برای بارگذاری Three.js CDN).

## کنترل‌ها

| کلید | عملکرد |
|------|--------|
| WASD | حرکت |
| Space | پرواز بالا |
| Shift | پرواز پایین |
| Ctrl | سرعت بیشتر |
| Q | حالت عادی (پیاده) |
| E | اشعه لیزری 👁️ |
| R | اشعه ایکس 🔬 |
| Click | فعال‌سازی قدرت |
| Scroll | تغییر فاصله دوربین |
| ESC | توقف |

## قدرت‌ها

### 🚶 حالت عادی (Q)
حرکت آزاد در دنیا — پیاده و پرواز

### 🔴 اشعه لیزری (E)
خط قرمز از چشم سوپرمن — هر بلوکی که بزند تخریب می‌شود
- ری‌کستینگ خطی از موقعیت بازیکن
- افکت نورانی و فلاش در نقطه برخورد

### 🔬 اشعه ایکس (R)
تمام بلوک‌های در شعاع ۱۲ بلوکی شفاف می‌شوند
- دید از درون زمین
- رنگ اصلی بلوک‌ها حفظ می‌شود

## دنیا

- ۴×۴ چانک (۶۴×۶۴ بلوک)
- تولید ترافیک با Perlin noise
- انواع بلوک: چمن، خاک، سنگ، آهن، الماس، چوب، برگ، شن، آب، برف
- درخت‌های تصادفی
- معادن (آهن ۱.۵٪، الماس ۰.۳٪)

## فناوری

- Three.js (CDN)
- Canvas/WebGL
- ES Modules
- بدون نیاز به build step
