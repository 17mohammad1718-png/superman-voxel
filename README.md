# 🦸 Superman Voxel Simulator

شبیه‌ساز سوپرمن در دنیای ماینکرافت — یک بازی مرورگری سه‌بعدی با Three.js

## نحوهٔ اجرا

### پیش‌نیازها

- یک مرورگر مدرن (Chrome، Firefox، Edge یا Safari) با پشتیبانی از **WebGL**
- **بدون نیاز به اینترنت** — Three.js r160 داخل مخزن است (`vendor/three.global.js`)؛ نه CDN، نه npm، نه build step
- بدون نیاز به نصب چیز دیگری

### روش ۱: باز کردن مستقیم فایل (ساده‌ترین)

۱. مخزن را دانلود یا کلون کنید:

```bash
git clone https://github.com/17mohammad1718-png/superman-voxel.git
cd superman-voxel
```

۲. فایل `index.html` را باز کنید (دابل‌کلیک یا کشیدن داخل پنجرهٔ مرورگر).

۳. روی دکمهٔ **Start** در صفحهٔ آغازین کلیک کنید و بازی را شروع کنید!

> ✅ دابل‌کلیک واقعاً کار می‌کند: Three.js به‌صورت یک اسکریپت کلاسیک (`vendor/three.global.js`) بارگذاری می‌شود، نه ES Module. ماژول‌ها روی `file://` توسط CORS مرورگر بلاک می‌شوند (origin اپاک) و صفحه سیاه می‌ماند — همان چیزی که پیام «Three.js failed to load» را حتی وقتی `vendor/` سالم بود به‌خاطر می‌آورد.

### روش ۲: با وب‌سرور محلی (توصیه‌شده برای توسعه)

از ریشهٔ پروژه یکی از این دستورها را اجرا کنید:

```bash
# پایتون
python3 -m http.server 8080

# یا Node.js
npx serve .
```

سپس در مرورگر به آدرس **http://localhost:8080** بروید.

اگر از VS Code استفاده می‌کنید، افزونهٔ **Live Server** هم گزینهٔ خوبی است: روی `index.html` راست‌کلیک کنید و «Open with Live Server» را بزنید.

### عیب‌یابی

پنل خطا (تمام‌صفحه، مشکی) دیگر یک پیام عمومی نیست؛ هر حالت واقعی را از هم تفکیک می‌کند:

| پیام پنل | معنی | راه‌حل |
|------|--------|--------|
| ⚠️ Three.js failed to load — *could not fetch* | `vendor/three.global.js` کنار `index.html` نیست | کل مخزن را دانلود/کلون کنید، نه فقط فایل HTML |
| ⚠️ Three.js failed to load — *did not define THREE* | فایل هست ولی ناقص/کش‌شده است | پوشهٔ `vendor/` را دوباره کپی کنید و با Ctrl+Shift+R ریلود کنید |
| ⚠️ WebGL is not available | Three.js سالم است ولی مرورگر context وب‌جی‌ال نمی‌دهد | Hardware acceleration را روشن کنید؛ در VM با `--ignore-gpu-blocklist` |
| ⚠️ The game failed to start | خطای واقعی کد با نام فایل و شمارهٔ خط نمایش داده می‌شود | متن داخل پنل (و کنسول F12) را بخوانید |
| صفحهٔ سیاه بدون پیام | نادر است؛ واچ‌داگ تا ۸ ثانیه صبر می‌کند | کنسول مرورگر (F12) را باز کنید |
| «DRAG TO LOOK» بالای صفحه | pointer lock در iframe/محیط امبدد مسدود است | با نگه‌داشتن کلیک چپ ماوس را بکشید تا دوربین بچرخد |
| کنترل‌ها کار نمی‌کند | صفحه فوکوس ندارد | ابتدا روی صفحهٔ بازی کلیک کنید |

## قدرت‌ها

### 🚶 حالت عادی (Q)
حرکت آزاد. با `F` بین **پرواز** و **پیاده‌روی با گرانش و پرش** جابه‌جا شوید.

### 🔴 اشعه لیزری (E)
خط قرمز از چشم سوپرمن — هر بلوکی که بزند تخریب می‌شود.
- ری‌کست دقیق ووکسلی (الگوریتم DDA آماناتیدس–وو)
- نگه‌داشتن کلیک = شلیک ممتد
- افکت نورانی و فلاش در نقطهٔ برخورد

### 🔬 اشعه ایکس (R)
تمام بلوک‌های دنیا شفاف می‌شوند — **به‌جز آهن و الماس** که توپر می‌مانند تا معادن به‌راحتی دیده شوند.

## دنیا

- ۴×۴ چانک (۶۴×۶۴ بلوک، ارتفاع ۳۲)
- تولید توپوگرافی با Perlin noise / fBm
- انواع بلوک: چمن، خاک، سنگ، آهن، الماس، چوب، برگ، شن، **آب**، برف
- دریا در ارتفاع ۹ با سواحل شنی
- درخت‌های تصادفی (بدون بریدگی روی مرز چانک‌ها)
- معادن (آهن ۱.۵٪، الماس ۰.۳٪)

## Seed

دنیا کاملاً قابل بازتولید است. seed در پایین-چپ صفحه نمایش داده می‌شود؛ روی آن کلیک کنید تا لینک دنیا کپی شود:

```
index.html?seed=4242
```

## فناوری و بهینه‌سازی

- Three.js r160 (محلی در `vendor/`، اسکریپت کلاسیک → سازگار با `file://`) · WebGL · بدون build step
- **`InstancedMesh`** به‌جای یک مش به ازای هر بلوک
- **Face culling با عبور از مرز چانک‌ها**
- **Voxel DDA** برای لیزر و برخورد دوربین به‌جای raycast روی کل صحنه
- **بازسازی تنبل چانک‌ها** (حداکثر ۲ چانک در هر فریم)
- **heightmap کش‌شده** برای مینی‌مپ
- PRNG قطعی (mulberry32) برای دنیای seed-محور

### نتایج اندازه‌گیری‌شده

| معیار | قبل | بعد |
|---|---|---|
| Draw call | ~۱۰٬۹۴۶ | **۹۳** (۱۱۸ برابر کمتر) |
| هزینهٔ راهی لیزر | تست روی ۱۱٬۰۰۰ مش | **~۴ میکروثانیه** |
| lookup مینی‌مپ | ~۱۱۵٬۰۰۰ در هر رفرش | **~۳٬۶۰۰** |
| بازسازی هنگام تخریب | کل چانک + کل صحنه | فقط چانک‌های dirty |

## فایل‌ها

```
superman-voxel/
├── index.html              ← بازی (single-file)
├── vendor/
│   ├── three.global.js     ← چیزی که index.html بارگذاری می‌کند (generated — ویرایش نکنید)
│   └── three.module.js     ← بیلد رسمی ES-module آپاستریم three@0.160.0 (منبع بازتولید)
├── tools/
│   └── make-three-global.js← ماژول → بیلد گلوبال، بدون وابستگی: node tools/make-three-global.js
├── REVIEW.md               ← گزارش بررسی فنی و نقشهٔ راه
└── README.md

اگر روزی نسخهٔ Three.js را عوض کردید، کافی است `vendor/three.module.js` را با بیلد جدید جایگزین کنید و `node tools/make-three-global.js` را اجرا کنید (`--check` هم دارد تا در CI مطمئن شوید فایل تولیدشده به‌روز است).
```
