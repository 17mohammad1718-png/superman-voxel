# 🦸 Superman Voxel Simulator

شبیه‌ساز سوپرمن در دنیای ماینکرافت — یک بازی مرورگری سه‌بعدی با Three.js

## نحوهٔ اجرا

### پیش‌نیازها

- یک مرورگر مدرن (Chrome، Firefox، Edge یا Safari) با پشتیبانی از **WebGL**
- **بدون نیاز به اینترنت** — Three.js به‌صورت محلی در پوشهٔ `vendor/` قرار دارد
- بدون نیاز به نصب چیز دیگری؛ بدون build step

### روش ۱: باز کردن مستقیم فایل (ساده‌ترین)

۱. مخزن را دانلود یا کلون کنید:

```bash
git clone https://github.com/17mohammad1718-png/superman-voxel.git
cd superman-voxel
```

۲. فایل `index.html` را باز کنید (دابل‌کلیک یا کشیدن داخل پنجرهٔ مرورگر).

۳. روی دکمهٔ **Start** در صفحهٔ آغازین کلیک کنید و بازی را شروع کنید!

### روش ۲: با وب‌سرور محلی (توصیه‌شده برای توسعه)

از ریشهٔ پروژه یکی از این دستورها را اجرا کنید:

```bash
# پایتون
python3 -m http.server 8080

# یا Node.js
npx serve .
```

سپس در مرورگر به آدرس **http://localhost:8080** بروید.

اگر از VS Code استفاده می‌کنید، افزونهٔ **Live Server** هم گزینهٔ خوبی است: روی `index.html` راست‌کلیک کنید و «Open with Live Server» را بزنید.

### عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| پیام «Three.js failed to load» | پوشهٔ `vendor/` باید کنار `index.html` باشد — کل مخزن را دانلود/کلون کنید، نه فقط فایل HTML |
| صفحهٔ سیاه | کنسول مرورگر (F12) را باز کنید و خطاها را چک کنید |
| کنترل‌ها کار نمی‌کند | ابتدا روی صفحهٔ بازی کلیک کنید تا فوکوس شود |

## قدرت‌ها

### 🚶 حالت عادی (Q)
حرکت آزاد. با `F` بین **پرواز** و **پیاده‌روی با گرانش و پرش** جابه‌جا شوید.

### 🔴 اشعه لیزری (E)
خط قرمز از چشم سوپرمن — هر بلوکی که بزند تخریب می‌شود.
- ری‌کست دقیق ووکسلی (الگوریتم DDA آماناتیدس–وو)
- نگه‌داشتن کلیک = شلیک ممتد
- افکت نورانی و فلاش در نقطهٔ برخورد

### 🔬 اشعه ایکس (R)
تمام بلوک‌های دنیا شفاف می‌شوند — **به‌جز آهن و الماس** که توپر می‌مانند تا معادن به‌راحتی دیده شوند.

## دنیا

- ۴×۴ چانک (۶۴×۶۴ بلوک، ارتفاع ۳۲)
- تولید توپوگرافی با Perlin noise / fBm
- انواع بلوک: چمن، خاک، سنگ، آهن، الماس، چوب، برگ، شن، **آب**، برف
- دریا در ارتفاع ۹ با سواحل شنی
- درخت‌های تصادفی (بدون بریدگی روی مرز چانک‌ها)
- معادن (آهن ۱.۵٪، الماس ۰.۳٪)

## Seed

دنیا کاملاً قابل بازتولید است. seed در پایین-چپ صفحه نمایش داده می‌شود؛ روی آن کلیک کنید تا لینک دنیا کپی شود:

```
index.html?seed=4242
```

## فناوری و بهینه‌سازی

- Three.js (محلی در `vendor/`) · WebGL · ES Modules · بدون build step
- **`InstancedMesh`** به‌جای یک مش به ازای هر بلوک
- **Face culling با عبور از مرز چانک‌ها**
- **Voxel DDA** برای لیزر و برخورد دوربین به‌جای raycast روی کل صحنه
- **بازسازی تنبل چانک‌ها** (حداکثر ۲ چانک در هر فریم)
- **heightmap کش‌شده** برای مینی‌مپ
- PRNG قطعی (mulberry32) برای دنیای seed-محور
